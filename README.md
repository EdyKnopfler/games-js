# Nave vs Discos Voadores!!

Jogo de nave (space shooter) em JavaScript puro, sem build e sem
dependências. Escrito originalmente em 2014 como material de apoio de um
livro sobre técnicas de jogos com JavaScript, acessível a iniciantes que
tinham acabado de aprender lógica de programação.

O projeto está em rework: a base é didática e funcional, mas tem débitos
técnicos conhecidos que vamos endereçando aos poucos.

## Como rodar

Abrir [index.html](index.html) direto no navegador (ou servir a pasta com
um servidor estático). Não há passo de build.
